# RASTERIZER-FROM-SCRATCH

## About The Project
This project is planned for have better understanding of rendering pipeline and implement performance-prioritzed renderer.

First, I implemenet renderer by using CPU only, and then after implemenent is done, I'll use CUDA to optimize the renderer. CPU rasterizer will use .OBJ file to load object, and render the object onto the screen, and fully interactable by user.
